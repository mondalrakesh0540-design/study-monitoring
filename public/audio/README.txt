# FocusGuard AI Audio Files Directory
Place your custom MP3 audio files here:
- start-study.mp3
- tab-change.mp3
- face-missing.mp3
- distracted.mp3
- back-to-study.mp3

Note: FocusGuard AI contains an automatic Web Audio Synthesizer fallback inside `src/utils/audioManager.js`. If MP3 files are omitted or missing, funny custom audio tones play automatically!
